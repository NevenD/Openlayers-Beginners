# Course Material OpenLayers beginners course

This repository contains example and project files from the Openlayers beginners course.

 **_Please read the following:_** 

## FAQ

### Q1: Where can I download the practice files?

**A:** If you're new to GitHub and just want to download source code, just click the green button saying "Clone or download" (positioned on the right side) and choose the "Download ZIP" option. Source code: [Github](https://github.com/NevenD/Openlayers-Beginners/tree/master/OPENLAYERS_BEGINNERS) 

### Q2: My code does not work. Where can I get help?

**A:** First, try fixing the problem on your own. If u didn't successed, then do the following:,  **post a detailed description of the problem to the Q&A area**, along with a code example (you can use https://codepen.io/pen/ or [jsfiddle](https://jsfiddle.net/) ). Or you can email me at:  neven.dimac@gmail.com. I will try to provide help as fast as possible.  

### Q3: Videos are blurred / have low quality, can you fix it?

**A:** Please open video settings and change the quality from 'Auto' to another value, for example 720p. If that doesn't help, please [contact the Udemy support team](https://support.udemy.com/hc/en-us).

### Q4: Are the videos downloadable?

**A:** Yes, all videos are downloadable on the Udemy platform. To download a video, use the small settings icon in the right bottom corner of the video player.

### Q5: How do I get my certificate of completion?

**A:** A certificate of completion is provided by Udemy after you complete 100% of the course. After completing the course, just click on the "Your progress" indicator in the top right-hand corner of the course page. If you want to change your name on the certificate, please [contact the Udemy support team](https://support.udemy.com/hc/en-us).
